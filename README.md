# 이덱떠 궤도

https://imatalkingpotato.github.io/idek-orbit/

익명으로 마음을 남기고 함께 공감·위로하는 공간. 한국 시간 자정마다 새 궤도가 열립니다.

## 실행

Node.js 22.13 이상에서 `npm ci`, `npm run dev`로 실행합니다. `npm test`는 날짜·궤도·반응 집계·실시간 이벤트 병합을 확인하고, `npm run build`는 타입 검사 후 정적 사이트를 만듭니다. `?demo=1`은 저장하지 않는 화면 미리보기입니다.

## 배포

`main`에 푸시하면 GitHub Actions가 검사와 빌드를 거쳐 GitHub Pages에 배포합니다. Vite base 경로는 `/idek-orbit/`입니다.

## 공유 데이터

Firebase Realtime Database의 별도 `idekorbit` 경로를 사용합니다. 기존 `confirmbell` 기록은 사용하거나 수정하지 않습니다. REST EventSource로 새 글과 반응을 받으며 연결이 끊기면 읽기를 재시도합니다. 반응마다 고유 ID를 기록해 재시도 중 중복 집계를 방지합니다. 첨부 이미지는 브라우저에서 최대 1,200px WebP로 압축합니다(GIF는 첫 프레임).

날짜별 저장 공간은 다음 한국 시간 자정을 키로 사용합니다. 새 글과 반응은 오늘만 기록할 수 있고 기존 글은 수정할 수 없습니다. 자정에는 화면이 새 궤도로 바뀌지만 기록은 남습니다. 날짜 드롭다운에서 지난 글·이미지·최종 반응 수를 읽기 전용으로 볼 수 있습니다. 예전 클라이언트의 삭제 요청도 데이터베이스 규칙에서 거부합니다. 아카이브 도입 전에 이미 삭제된 글은 복구하지 않습니다.

`?day=YYYY-MM-DD&thought=글ID` 링크는 해당 날짜의 글을 엽니다. 당일 링크는 실시간 화면, 지난 날짜는 아카이브로 연결됩니다.

`firebase.rules.json`은 **이 사이트의 규칙만** 담았습니다. 기존 데이터베이스에 적용할 때 다른 서비스의 규칙을 덮어쓰지 말고 `idekorbit` 항목만 병합해야 합니다. 데이터베이스 주소는 공개 클라이언트 주소이며 관리자 자격 증명은 이 저장소에 포함하지 않습니다.

## Slack 새 글 알림

`integrations/OrbitSlack.gs`를 전용 Google Apps Script 프로젝트에서 실행합니다. 스크립트 속성 `SLACK_WEBHOOK_URL`에는 **온보딩-채널에디터**로 연결된 Incoming Webhook만 저장합니다. 비밀값은 저장소나 프런트엔드에 넣지 않습니다.

`startOrbitNotifications`를 실행하면 설치 이후 새 글만 확인하는 1분 간격 트리거가 만들어집니다. `testOrbitNotification`은 연결 테스트 1건을 전송합니다. 글 내용은 plain_text로 보내 사용자 입력이 Slack 멘션이나 링크 명령으로 해석되지 않도록 합니다. 이미지는 Slack에 재업로드하지 않고 원래 글 링크로 엽니다.

전송 성공 이후에만 중복 방지 표식을 남기고, 실패하면 다음 실행에서 다시 시도합니다. 자정을 넘긴 미전송 글도 처리합니다. 다만 Slack이 수신한 직후 응답이나 성공 표식 저장이 실패하는 극단적인 경우에는 중복 알림이 생길 수 있습니다. Google 트리거 지연에 따라 알림이 1분보다 늦을 수 있습니다. 기존 Airtable 발행 알림 스크립트와는 별도 프로젝트입니다.
